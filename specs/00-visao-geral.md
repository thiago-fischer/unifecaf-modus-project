# Visão geral do projeto

## Nome do projeto

**Modus**

## Subtítulo

**O custo por trás da inteligência**

## Contexto

O uso de ferramentas de Inteligência Artificial generativa se tornou cada vez mais comum em atividades acadêmicas, profissionais e pessoais. Usuários utilizam LLMs para resumir textos, gerar códigos, escrever mensagens, criar ideias e resolver dúvidas.

Apesar disso, o custo computacional por trás dessas interações normalmente não é visível. Para o usuário final, enviar um prompt parece uma ação simples e sem impacto. Porém, cada geração envolve processamento, uso de infraestrutura e cobrança baseada em tokens.

O projeto **Modus** nasce com a proposta de tornar esse custo mais compreensível por meio de uma aplicação simples, educativa e acessível.

## Problema

Usuários de Inteligência Artificial generativa frequentemente não têm percepção clara de que prompts, respostas longas e escolha de modelos maiores podem gerar maior custo computacional e financeiro.

Essa falta de percepção pode levar ao uso pouco consciente da tecnologia, como solicitar respostas excessivamente longas, repetir prompts por falta de clareza ou utilizar modelos mais robustos para tarefas simples.

O problema principal que o projeto busca resolver é:

**Como tornar visível, de forma simples e educativa, o custo estimado por trás de uma interação com uma LLM?**

## Proposta

O **Modus** será uma aplicação web que permite simular o custo aproximado de uma geração feita por IA.

O usuário poderá escolher:

- a LLM desejada;
- o tipo de tarefa;
- o tamanho esperado da resposta.

Com base nessas informações, o sistema apresentará:

- estimativa de tokens de entrada;
- estimativa de tokens de saída;
- custo aproximado da geração;
- comparação entre modelos;
- orientação sobre uso consciente de IA.

O projeto não tem como objetivo calcular a pegada ambiental real da geração, pois isso exigiria informações específicas sobre datacenters, matriz energética, hardware utilizado e infraestrutura do provedor. O foco inicial será a conscientização por meio de estimativas de tokens e custo.

## Público-alvo

O público-alvo do projeto são pessoas que utilizam ou desejam utilizar ferramentas de IA generativa de forma mais consciente.

Esse público inclui:

- estudantes;
- professores;
- profissionais que utilizam IA no trabalho;
- usuários iniciantes de LLMs;
- pessoas interessadas em sustentabilidade digital;
- pessoas que utilizam ferramentas como ChatGPT, Gemini, Claude ou similares.

## Resultado esperado

O resultado esperado é consolidar uma proposta clara para o projeto, permitindo que o grupo avance para a etapa de definição do MVP.

Ao final desta etapa, o projeto deve possuir uma visão objetiva sobre:

- qual problema será resolvido;
- quem será beneficiado;
- qual resultado o sistema pretende entregar;
- quais limites devem ser respeitados para evitar um escopo inviável.

## Indicadores iniciais de sucesso

A visão geral do projeto será considerada concluída quando:

- o problema principal estiver descrito de forma objetiva;
- o público-alvo estiver definido;
- a proposta do projeto estiver documentada;
- o resultado esperado estiver claro;
- os limites da proposta estiverem registrados;
- o grupo conseguir explicar o projeto de forma simples;
- o projeto estiver alinhado ao tema de sustentabilidade digital;
- a proposta for viável para evoluir para um MVP simples.

## Fora do escopo desta etapa

Nesta etapa, não serão definidos:

- funcionalidades detalhadas;
- stack tecnológica;
- arquitetura do sistema;
- layout final;
- regras completas de cálculo;
- integração com APIs reais de LLM;
- banco de dados;
- autenticação de usuários.

Esses pontos serão tratados em etapas futuras do projeto.

## Riscos

O principal risco desta etapa é manter a proposta vaga demais, gerando retrabalho durante a construção do MVP.

Para reduzir esse risco, o projeto assume desde o início que o Modus será uma ferramenta educativa de estimativa, e não uma calculadora exata de impacto ambiental.
