# Especificações do projeto

Esta pasta concentra as decisões, regras e critérios que orientam o desenvolvimento do projeto. Ela é a referência compartilhada do grupo e deve evoluir por meio de issues e pull requests.

## Estado atual

O projeto está na fase de preparação. Ainda não há implementação de produto nesta branch; o objetivo desta etapa é alinhar o modo de trabalho da equipe.

## Documentos

- [Visão geral do projeto](./00-visao-geral.md): contexto inicial, objetivos e limites desta fase.
- [Fluxo de colaboração](./01-fluxo-de-colaboracao.md): branches, commits, issues, revisão e merges.
- [Critérios de aceite e Definition of Done](./02-criterios-de-aceite-e-conclusao.md): como avaliar e concluir um trabalho.
- [Modelo de issue](./templates/issue.md): roteiro para registrar uma demanda executável.
- [Modelo de pull request](./templates/pull-request.md): roteiro para propor uma alteração.

## Como alterar uma especificação

1. Abra uma issue explicando a mudança necessária.
2. Crie uma branch vinculada à issue.
3. Atualize a especificação por meio de um pull request.
4. Solicite revisão de pelo menos um colaborador.
5. Faça o merge somente após os critérios de aceite serem atendidos.

Decisões que alterem o objetivo, o escopo ou o fluxo do projeto devem ser registradas aqui; acordos feitos apenas em conversas não substituem a documentação versionada.
