# Como contribuir

Obrigado por contribuir com este projeto. O desenvolvimento é organizado por issues, branches e pull requests.

Leia primeiro o [fluxo de colaboração](./specs/01-fluxo-de-colaboracao.md) e os [critérios de aceite](./specs/02-criterios-de-aceite-e-conclusao.md).

Resumo do fluxo:

1. escolha ou crie uma issue;
2. crie uma branch a partir da `main`, usando o número da issue;
3. faça commits pequenos e relacionados à tarefa;
4. abra um pull request para a `main`;
5. peça revisão de pelo menos uma pessoa;
6. resolva os comentários e faça o merge após a aprovação;
7. confirme o fechamento da issue.

Enquanto o projeto ainda estiver sem implementação, alterações de documentação e de configuração do fluxo também devem seguir esse processo. Não faça push direto na `main`.
